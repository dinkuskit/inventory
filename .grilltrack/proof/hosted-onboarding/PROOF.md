## Fidelity and outstanding integration

The service uses actual local workerd SQLite Durable Objects and existing stock
kernel commands. The proof host supplies the config/environment constants
normally generated by Astro. It is not a full Astro site or Registry install.
Identity/token endpoints are synthetic. Reserved `.invalid` proof origins get
synthetic public DNS answers for the host's SSRF guard, with HTTP transported
entirely locally; this does not prove real DNS or endpoint connectivity.
The guard and declared allowed-host checks remain enabled.

The original sandbox device-grant check failed on reserved-name DNS, then the
reinstall fixture used the wrong host table. Both harness faults were corrected;
the passing rerun above replaces that initial failed draft evidence. Foreign
operation rejection exposed a stuck frozen intent; the plugin now clears only
that matching, definitively rejected intent and permits safe selection again.

Real account identity/consent/site grants/renewal, live hosting, verified publisher,
Registry installation/publication and stock receiving/adjustment screens remain
unproven. Placeholder origins fail closed, and an unconfigured account service
returns HTTP 503. No trial duration, quota, price or permanent-free promise was
invented. The three product decisions are verified only for this bounded local
setup slice, not for the complete hosted product.
